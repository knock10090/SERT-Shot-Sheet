# SERT Digital Shot Sheet — 0.8.0

Standalone administrative test build for GitHub Pages. The charge worksheet is included.

## Put it on GitHub

1. Unzip this archive.
2. Create a repository and upload **these files themselves** to the repository root. Do not upload the zip, and do not leave the files inside an extra folder.
3. Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. Open the Pages address on a phone and add it to the Home Screen.

The site is static. Reports stay in the browser on that phone. They are not encrypted. Use fictitious data only.

## Worksheet

- LBS = total grains / 7000
- LBS TNT = LBS × R.E. factor (default 1.66)
- MSD (ft) = K factor (default 18) × cube root of LBS TNT
- Room volume = length × width × height, in feet
- PSI = (LBS TNT / volume)^0.72 × 2410
- Limits shown on the sheet: 4 PSI exterior, 2 PSI interior

This is not an approved operational form and not a safety determination.
